## Composition notes

Give the group a name and name individual avatars. Overflow count text should describe how many people are omitted with aria-label. The group composes existing Avatar parts; it does not fetch people or manage selection.

The preview uses Hextech brand marks and [shadcn�s GitHub avatar](https://github.com/shadcn.png). Replace the image URLs with your own assets when copying this example. Initials appear only if an image cannot load.
