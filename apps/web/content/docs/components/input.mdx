## Labels and state

Associate a visible label with `id`, or compose Input inside [Field](/docs/components/field). Use `value` with `onChange` for controlled editing, or `defaultValue` for uncontrolled editing. Keep a controlled text value a string throughout its lifetime. See [Forms](/docs/forms) for validation.
