## Composition notes

Pair value with onValueChange for controlled selection, or use defaultValue for local state. Each checkbox needs a stable value and a visible label. For a parent checkbox, provide allValues and set parent on Checkbox; mixed state is derived by Base UI. Use Field and FieldLabel for group validation and naming.
