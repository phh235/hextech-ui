## API reference

These are the main Typography options. See the exported TypeScript types for inherited native or primitive props.

| Prop   | Type                                       | Default   |
| ------ | ------------------------------------------ | --------- |
| `as`   | `h1–h6 (Heading), p \| span \| div (Text)` | `h2 / p`  |
| `size` | `sm \| md \| lg \| xl (Heading)`           | `lg`      |
| `tone` | `default \| gold \| muted (Heading)`       | `default` |

{/* END GENERATED REFERENCE */}

## Semantic text

Choose `as` for the document hierarchy and `size` for the visual scale. Do not skip heading levels to get larger text. Associate Label with a control through `htmlFor`.
