## Debounced search

`onValueChange` updates editing immediately. Use `onSearch` for filtering or requests and set `debounceMs` to delay that callback. Keep `value` paired with `onValueChange` for controlled text, or use `defaultValue`. Cancel stale requests in your data layer.
