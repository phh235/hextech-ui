## API reference

These are the main Button options. See the exported TypeScript types for inherited native or primitive props.

| Prop      | Type                                                               | Default     |
| --------- | ------------------------------------------------------------------ | ----------- |
| `variant` | `primary \| secondary \| text \| hextech \| dimmed \| destructive` | `secondary` |
| `size`    | `small \| medium \| large`                                         | `medium`    |
| `shape`   | `normal \| square \| round`                                        | `normal`    |
| `loading` | `boolean`                                                          | `false`     |
