## Composition notes

Compose InputGroupInput with inline addons, or InputGroupTextarea with block addons. Keep the input before addon actions in DOM order; align controls only the visual position. Use a real Button for actions, and keep a visible field label outside the group. The implementation reuses Group, Input, Textarea and Button.
