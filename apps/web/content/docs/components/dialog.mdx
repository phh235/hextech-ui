## Open state and focus

Use `open` with `onOpenChange` for controlled visibility, or `defaultOpen` for an initial local state. Include DialogTitle and an appropriate description. Escape dismisses a normal dialog; focus returns to its trigger. Portal content inherits the scoped theme.

## Corner close button

DialogContent includes a gold-ring close button at the top right. Set `showCloseButton={false}` to omit it, or set `closeLabel` to a localized accessible name. The existing DialogClose remains available for footer actions. Closing restores focus to the trigger.
