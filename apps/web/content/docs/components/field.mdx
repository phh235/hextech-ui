## Validation and forms

Use `FieldLabel`, `FieldDescription` and `FieldError` inside `Field` so labels and messages remain associated with the control. Set `invalid` for an external validation error. The default label-to-control gap is 8px.

See [Forms](/docs/forms) for a complete React Hook Form and Zod example with submission, reset and server errors.
