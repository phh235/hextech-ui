## API reference

These are the main Multiple Select options. See the exported TypeScript types for inherited native or primitive props.

| Prop                               | Type                                              | Default                   |
| ---------------------------------- | ------------------------------------------------- | ------------------------- |
| `label`                            | `string (required)`                               | `—`                       |

## Object records

Use stable `getOptionKey` values and readable `itemToStringLabel` text for object options. Own selections with `value` and `onValueChange`, or seed local state with `defaultValue`. Use `isOptionDisabled` for unavailable choices and keep the label visible.
