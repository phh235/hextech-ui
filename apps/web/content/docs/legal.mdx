## LoL Math UI

Hextech UI is an independent adaptation of [LoL Math UI](https://ui.lolmath.net/) for Base UI. The original component visual design and interaction reference come from [LoL Math's authors and contributors](https://github.com/lolmath/lolmath/tree/main/packages/ui).

The upstream `@lolmath/ui` package declares the **ISC** license. Reused or adapted upstream code and styles retain that license and their notices. Hextech UI contributes its Base UI integration, source registry, documentation and original brand assets. Source versions and the outstanding upstream notice verification are recorded in [THIRD_PARTY_NOTICES.md](https://github.com/phh235/hextech-ui/blob/HEAD/THIRD_PARTY_NOTICES.md).

## Fonts and visual references

UI components use Cinzel and Barlow from Fontsource under SIL OFL 1.1, as substitutes for Beaufort and Spiegel. Documentation text uses Geist and code uses JetBrains Mono, with their original OFL notices. Font licenses and provenance are recorded in [THIRD_PARTY_NOTICES.md](https://github.com/phh235/hextech-ui/blob/HEAD/THIRD_PARTY_NOTICES.md).

Implementations use Base UI or semantic HTML. No upstream raster assets, proprietary font binaries or audio are bundled. A package-level code license does not grant rights to Riot assets.
