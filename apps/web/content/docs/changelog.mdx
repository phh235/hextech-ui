## Unreleased

### Components

- Added controls, fields, overlays, collections, calendars and optional charts.
- Refined hover, pressed, focus and disabled states against the LoL Math reference.
- Corrected Switch thumb movement, calendar range styling and disabled interactions.
- Added keyboard and touch alternatives for collection editing.

### Documentation

- Adopted native Fumadocs layouts, buttons, search, tabs and code blocks.
- Added light and dark modes for the website, previews and overlays.
- Simplified component pages to Preview/Code with an A–Z index.
- Added a focused installation guide and separate contributor instructions.
- Added documentation chat, Markdown pages and LLM-friendly endpoints.

### Installation

- Added a shadcn-compatible registry with JavaScript and TypeScript output.
- Added local packed-package builds and consumer checks.

This is a development version. No public npm release has been published.
