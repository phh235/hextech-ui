[Browse the full-width block gallery](/blocks). Each block composes Hextech UI components and installs through a declared registry dependency graph. Demo data and actions stay local; no backend is implied.

- [Account access](/docs/blocks/auth): Login, signup and recovery forms with native validation and clearly local mock results.
- [Profile and preferences](/docs/blocks/account): A profile, practice panel, editable preferences and dismissible activity notices.
- [Party lobby](/docs/blocks/lobby): Five party slots, local invitations, ready state and a cancellable matchmaking preview.
- [Draft room](/docs/blocks/draft): An original fictional roster with role filters, selection, a gesture-started countdown and lock-in.
- [Training HUD](/docs/blocks/hud): Local health, energy, ability cooldowns and a keyboard-friendly ping menu. Default silent.
