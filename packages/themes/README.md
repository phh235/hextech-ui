# @hextech-ui/themes

Hextech UI — League-inspired components. Open by design.

Proposed package identifier. Scope ownership is unverified; publishing is disabled. Use through the local workspace or test tarballs only.

See the repository README and architecture documentation for exports and setup. Hextech UI additions are MIT licensed; upstream materials and dependencies retain their own licenses. See the repository [third-party notices](https://github.com/phh235/hextech-ui/blob/HEAD/THIRD_PARTY_NOTICES.md).

`hextech.css` imports Latin Cinzel (500/700/900) and Barlow (400/500/600/700) from pinned Fontsource 5.3.0 dependencies. They are SIL OFL 1.1 fonts, with original notices in those distributions. Preserve those notices when redistributing built font assets. No external font service or proprietary Riot font is required.

Hextech UI is an independent, community-driven project inspired by League of Legends. It is not affiliated with or endorsed by Riot Games.
