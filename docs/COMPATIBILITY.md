# React Aria replacement contracts

This is an original library, not a drop-in React Aria adapter. Source 9.7.0 directly reexports these surfaces; types and framework implementation classes are explicitly accounted for.

| Upstream surface                                   | Replacement                                                                                                 | Contract / difference                                                                                                                                                                                |
| -------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Dialog, DialogTrigger, UnstyledPopover, FieldError | Dialog/Trigger, Popover/Content, FieldError                                                                 | Base UI composition, controlled open, focus and portals. No RAC contexts.                                                                                                                            |
| Focusable, Pressable                               | Native focusable elements / Base UI render composition                                                      | One semantic button/link; merge refs and handlers. Arbitrary spans are not silently promoted to buttons.                                                                                             |
| ListBoxItem, Collection                            | SelectItem, typed Combobox/MultipleSelect options, AutocompletePrimitive and keyed Tree/Tags/DataTable data | No detached RAC collection-building pass. Parts/data belong to their documented owner.                                                                                                               |
| useListData, ListData                              | useListData / ListDataOptions                                                                               | Immutable keyed append/prepend/insert/update/remove/move/replace, filtering and selection. Nonempty unique string IDs.                                                                               |
| useAsyncList, AsyncListData/Options                | useAsyncList / AsyncListOptions                                                                             | AbortSignal, filter/sort, cursor pages, reload, errors and stale-completion protection. Duplicate IDs across pages reject. No implicit network endpoint.                                             |
| Virtualizer, ListLayout                            | VirtualListbox; optional useVirtualizer/useWindowVirtualizer                                                | Actual windowing, mounted active descendant, position/set-size semantics and keyboard selection. MIT TanStack Virtual, since Base UI has no virtualizer.                                             |
| GridLayout, TableLayout, WaterfallLayout, Size     | Headless virtualizer lanes/estimateSize/measureElement and native dimensions                                | RAC constructors are not exported. Measured grids/masonry require application composition; no finished masonry component is claimed. Rich table defaults to pagination.                              |
| useDragAndDrop and related transfer types          | Removed from the distributed library at the maintainer’s request (2026-10-18)                               | No Drag and Drop hook, docs, registry item or package export is shipped. Tree keyboard moves and owner-controlled table reordering remain independent APIs. Prior transfer acceptance is historical. |
| RouterProvider                                     | Native anchors / application router composition                                                             | No Next.js dependency or global router provider.                                                                                                                                                     |
| DateValue, TimeValue                               | ISO Gregorian days, HH:mm strings, DateRange                                                                | Native segmented editing + original APG calendar. No non-Gregorian or internationalized-date object compatibility.                                                                                   |
| Key, Selection                                     | String IDs and readonly string arrays                                                                       | Explicit selections; no special all sentinel.                                                                                                                                                        |
| SortDescriptor/Direction                           | ListSortDescriptor or rich-table SortingState                                                               | Explicit translation: hook column + ascending/descending; TanStack descriptor for table.                                                                                                             |
| Chart grammar/scales/tooltip/types                 | Optional charts subpath reexports                                                                           | Current MIT engine 1.1.0. Original frame/legend/presets. No Vue wrapper. Categorical presets use equally spaced x positions; generic grammar supports continuous/time axes.                          |

These boundaries do not prove keyboard, screen-reader or visual parity. Framework-specific classes, non-Gregorian calendars, generic masonry and cross-window keyboard drag/drop are disclosed compatibility limitations for release review. Runtime has no React Aria dependency.

Combobox/MultipleSelect accept generic object records with stable keys, custom labels/rows/chips, disabled choices and form IDs. Autocomplete is a separate free-text primitive rather than a selection alias. Unstyled Base UI parts are exported for grouped/inline/virtualized custom compositions; RAC context-object identity is not promised. Radio/Switch own their indicator/track children; visible labels belong outside the control.
